Portal Maintenance Request

Allow portal users to create, track, update, and discuss maintenance requests — no backend access needed

Video Overview

Features

1 Portal dashboard

A Maintenance Requests entry appears automatically on the portal home page with a live counter showing how many requests the user has submitted.

Portal Dashboard
List View

2 List view with filters

Browse all submitted requests in a clean table view. Search by subject, description, or equipment. Sort by date, name, stage, or priority. Filter by Open, Done, or Cancelled. Group by stage, priority, or type.

3 Create from portal

Click New Request to open a clean form. Fill in the subject, select equipment (optional), choose type (corrective/preventive), set priority, and describe the issue. One click to submit.

Create Request
Request Detail

4 Request detail page

View full request details: stage, date, priority, type, equipment, and description. Status badges show Open, Done, or Cancelled at a glance. Navigate between requests with prev/next arrows.

5 Update from portal

While a request is still Open, users can click Update This Request to modify the subject, equipment, type, priority, or description. Once a request is Done or Cancelled, it becomes read-only.

Update Request
Discussion Thread

6 Discussion thread

Each request includes a built-in chatter section. Portal users can post messages, and internal users can reply from the backend — keeping all communication in one place. The requester is automatically subscribed after submission.

7 Backend integration

Portal-created requests appear in the standard Maintenance → Maintenance Requests backend view. A dedicated Portal Requests filter plus Created From Portal and Portal User fields let internal users quickly identify portal submissions.

Backend Integration

And much more...

Record-Level Security

Portal users can only see and interact with their own requests. Enforced via Odoo IR rules — no data leaks.

Form Validation

Server-side validation for all form fields. Invalid input is caught with clear error messages before anything is saved.

Prev/Next Navigation

Navigate between requests with previous/next arrows on the detail page, just like standard Odoo portal pages.

Breadcrumb Navigation

Full breadcrumb support across all portal pages: list, detail, and create views.

Status Badges

Color-coded badges (Open, Done, Cancelled) on both the list and detail views for instant status recognition.

Multi-Company

Equipment selection respects multi-company rules. Requests are tied to the user’s current company.
